# SkateFlicks 🎬

The definitive encyclopedia of skateboarding films & video parts.

**🔗 Live:** [clawdiard.github.io/skateflicks](https://clawdiard.github.io/skateflicks/)

## What It Is

A curated, searchable encyclopedia of the greatest skateboarding videos ever made — from the 1984 Bones Brigade Video Show to modern classics like Purple Playgrounds.

## Features

- 🎬 **20 iconic films** with descriptions, featured skaters, and watch links
- 🔍 **Search** by film name, company, or skater
- 🏷️ **Genre filters** — Street, Vert, Art House, Cinematic, and more
- 📊 **Sort** by year, rating, or alphabetically
- 📅 **Timeline view** organized by decade
- 📱 **Fully responsive** — works on any device
- 🌙 **Dark theme** with vibrant accent colors

## Tech Stack

- Vanilla HTML/CSS/JS — no dependencies
- Static JSON data file
- Hosted on GitHub Pages

## Contributing

Want to add a film? Edit `data/films.json` and submit a PR!
